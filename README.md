<h1>MIPS microprocessor using VHDL (single-cycle and pipeline)</h1>
Designed and implemented MIPS microprocessors using
VHDL, including a single-cycle version and a pipelined
version with instruction-level parallelism. Focused on
optimized datapath design, control logic, and precise timing
to ensure correct and efficient execution across data,
control, and structural hazards.
